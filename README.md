# ATG Digital Website

Siyah-altın temalı, responsive statik site.

## Dosyalar
- `index.html`: Ana sayfa
- `pages/hizmetler.html`: 4 hizmet kartı
- `pages/hizmet-tasarim.html`
- `pages/hizmet-sosyal-medya.html`
- `pages/hizmet-video.html`
- `pages/hizmet-reklam.html`
- `pages/projeler.html`
- `pages/hakkimizda.html`
- `pages/iletisim.html`
- `assets/css/style.css` ve `assets/js/main.js`

## GitHub Pages
Tüm dosyaları deponun köküne, klasör yapısını koruyarak yükle. GitHub > Settings > Pages altında `Deploy from a branch`, `main`, `/(root)` seç.

Görseller Unsplash üzerinden yüklenir ve internet bağlantısı gerektirir. Örnekler konsept görselleridir, gerçek müşteri işleri olarak gösterilmez. İletişim formu otomatik gönderim yapmaz; mesajı hazırlar ve Instagram'ı açar.
